KAMARUPA INSCRIPTIONS — STANDALONE ATLAS

OPEN
Double-click Inscriptions-Atlas.html to open it in a modern browser.
The map, catalogue and embedded summaries work offline. Keep atlas-assets
and maps beside the HTML file. Source PDFs and separate summary TXT files
are linked from their existing locations in this Primary source folder.
External source websites and OpenStreetMap links require internet access.

CONTENTS
53 catalogue records; 48 have geographic references and five remain unmapped.
Use search, material, location precision and date range filters. The principal
350–1100 CE catalogue filter selects the 38 records marked within that scope.
The full list includes later contextual records and uncertain dates.
Shared or nearby markers are grouped; click a group to choose an inscription.
Use All locations to include the external records beyond Assam. Drag to pan,
use the wheel or +/- to zoom. Map markers support Tab then Enter or Space.
Press / to search and Escape to close details. About explains the evidence.

LOCATION CAUTION
Coordinates can mark monuments, nearby towns, landmarks or regional anchors.
Dashed markers signal approximate or user-supplied references. Each record
shows its coordinate evidence and uncertainty. Decimal places do not imply
survey precision. Barpanara and the three Deopani records preserve the user's
supplied coordinates, with their provenance clearly labelled.
Modern outlines are geographic context, not ancient political boundaries.
This working catalogue is not certified exhaustive.

DATA UPDATES
The displayed data is a bundled snapshot of Kamarupa-Inscriptions-Chronology.csv.
After changing that CSV or the summary TXT files, run from this folder:
  python3 atlas-assets/refresh_atlas.py
Then reload the HTML. No packages or web server are required.
The original CSV remains the source of truth; filters do not edit it.

MAPS AND CREDITS
The maps folder was copied from Assam History/data/maps. Its original JSON
files and README.md are retained. atlas-geography.js is the derived offline
map bundle. See maps/README.md for original sources and licence details.
Country outlines use Natural Earth public-domain data. Other copied layers
retain their original attribution and any stated licence limitations.
